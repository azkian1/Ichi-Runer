# Bundled resources

Three.js r180 (0.180.0) is bundled locally with its MIT license.

Cormorant Garamond and Manrope are bundled as Latin WOFF2 subsets with their SIL Open Font License notices. Gameplay uses local procedural geometry, textures and shaders.

The six audio files are preserved from the original Ichi game. Runtime code loads no remote assets.
